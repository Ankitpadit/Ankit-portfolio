# Ankit Padit — Frontend Portfolio

A responsive portfolio starter project built with HTML, CSS, and vanilla JavaScript.

## Features
- Responsive layout for desktop, tablet, and mobile
- Semantic page sections and accessible navigation labels
- Mobile navigation toggle
- Skills and project cards
- Contact form with client-side validation
- No build tools or dependencies required

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Edit the text in `index.html` to reflect your real skills and completed work.

## Important customization
- Update the name, about section, skills, and project descriptions so they truthfully represent your experience.
- Skill bars are illustrative placeholders, not measured scores.
- The Task Tracker card is a planned concept, not an implemented application.
- The contact form only validates input in the browser. It does not send or store messages.
- Replace placeholder project content with actual projects before using this as a professional portfolio.

## Technologies
- HTML5
- CSS3 (Flexbox, Grid, media queries)
- JavaScript (DOM events and form validation)
